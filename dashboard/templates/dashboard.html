📖 How it works

SoftNet-Guard sends the URL to Google Safe Browsing API v4, which checks it against Google's constantly updated lists of unsafe web resources including malware sites, phishing pages, and social engineering content.

This is the same technology used by Google Chrome, Firefox, and Safari to protect billions of users worldwide.
